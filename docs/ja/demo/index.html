WorldNetのデモ

トップ | GitHub | English

このページは、WorldNetをWebAssemblyとして、ブラウザーの中で動かします。音声は外部へ送りません。下の音声から、HarvestがF0の系列を、CheapTrickがスペクトル包絡を、D4Cが非周期性指標を推定し、Synthesisがそれらから波形を作り直します。音の高さの変更は、合成の前にF0へ倍率を掛けて行います。

元の音声

“His nature must have been kindly.”

音声: Linda Johnson氏がLibriVox向けに録音したもので、Keith Ito氏のLJ Speech Datasetから引用しています。このデータセットはパブリックドメインです。

結果



Harvestが推定したF0の系列です。音の高さの変更の前の値です。
