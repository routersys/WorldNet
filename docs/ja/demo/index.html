WorldNetのデモ

トップ | GitHub | English

このページは、WorldNetをWebAssemblyとして、ブラウザーの中で動かします。音声は外部へ送りません。Harvest、CheapTrick、D4Cが、音声を一度だけ解析して、F0の系列、スペクトル包絡、非周期性指標を求めます。Synthesisはその3つから波形を作ります。下の操作は、合成の前にその3つを変えます。

1. 音声

“His nature must have been kindly.”

音声: Linda Johnson氏がLibriVox向けに録音したもので、Keith Ito氏のLJ Speech Datasetから引用しています。このデータセットはパブリックドメインです。

ファイルはブラウザーの外へ出ません。ブラウザーがモノラルへ復号し、可能なら22.05kHzにします。使うのは最初の10秒だけです。

2. 声の変換

  • ロボットは、有声のすべてのフレームへ、有声フレームの中央値のF0を与えます。ささやきは、どのフレームも有声にしません。
  • 音の高さは、F0へ倍率を掛けます。速さは、フレームを時間方向に取り直し、音の高さを変えません。
  • フォルマントは、スペクトル包絡を周波数の軸の方向に伸び縮みさせます。息の混ざり方は、非周期性指標へ倍率を掛けます。

3. スペクトル包絡の符号化

Codec.CodeSpectralEnvelopeが、すべてのフレームの包絡を、選んだ個数の値へ減らし、Codec.DecodeSpectralEnvelopeが復元します。下の音声は、復元した包絡から合成しています。

4. F0推定器

Harvestは、解析のときに実行済みです。ボタンを押すと、同じ音声でDioと、StoneMaskで補正したDioを実行し、3つの系列と所要時間を比べられます。
